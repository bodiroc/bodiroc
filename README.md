# bodiroc.com

Website for Bodi Roc Personal Fitness Training (Shelly Shubert), a Total Fitness Concept since 1981.

- Plain static site: `index.html`, images in `img/`, old Wix URLs redirected in `_redirects`.
- Hosted free on Cloudflare Pages. Any change saved to `main` republishes automatically.
- `<meta name="robots" content="noindex">` in `index.html` keeps search engines away until launch; remove it when bodiroc.com points here.
